# MCore Mod Loader — Atualizações

Este repositório guarda **apenas os instaladores** do MCore Mod Loader.
O código-fonte fica em um repositório privado.

## Como instalar

Abra a aba **[Releases](../../releases)** e baixe o arquivo
`MCore-ModLoader-Setup-<versão>.exe` da versão mais recente.

> O Windows SmartScreen pode avisar "editor desconhecido", porque o instalador
> ainda não é assinado. Clique em **Mais informações → Executar assim mesmo**.

## Atualizações automáticas

Com o app instalado, ele verifica este repositório ao abrir e a cada 30 minutos.
Quando sai uma versão nova, ela é baixada em segundo plano e o app mostra o botão
**Reiniciar** para instalar.

Os Releases daqui são criados automaticamente pelo GitHub Actions do repositório
do código — não é preciso subir arquivos manualmente.
